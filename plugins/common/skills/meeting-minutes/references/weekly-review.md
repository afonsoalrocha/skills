# Weekly review deck

A weekly alignment deck is prepared before the meeting and saved next to the minutes.

## Steps

1. Read the previous minutes (open actions, milestones) and query the work board or
   tracker for the current state of each item.
2. Sort the items into three blocks:
   - pending (open, with owner and due date)
   - completed since the last meeting
   - next priorities
3. Build the deck from the team template with `stakeholder-deliverables`
   (`references/deck-structure.md`): key numbers first, source on every slide.
4. Render and review every slide, show the preview to the human.
5. Save as `YYYY-MM-DD_meeting_name_presentation.pptx`, beside
   `YYYY-MM-DD_meeting_name_minutes.pdf`, using the same base name.

## Rules

- Statuses come from the board at generation time, not from memory of the last meeting.
- Do not mark anything completed without the owner's confirmation or a board state that
  says so; unclear items go to pending with a note.
- If the deck was built inside a task folder, the recurring final file is still copied to
  the minutes folder; it does not live only in the task's outputs.
