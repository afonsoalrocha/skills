# Syncing access across assets

- Access changes are additive: add the grant that is missing, never lower a stronger grant
  a person already has.
- Discover the assets live (the container plus the published assets of the project) instead
  of using a fixed list, so assets added later are covered.
- A person who does not exist or is inactive in the tool: stop and report; do not provision
  the account.
- Plan first, then apply, then read back the effective access and record it in the
  container's changelog.
- Access to a container does not flow to the assets inside it; grant and verify per asset.
