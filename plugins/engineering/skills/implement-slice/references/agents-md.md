# The repository AGENTS.md

A living file the agent reads every session. Keep it short.

- Commands: install, test, lint, typecheck, run locally.
- System invariants and code rules.
- Traps that have already been hit ("each line is a scar", Akita).
- Every new failure becomes a line here or a test. What a machine can enforce becomes a check, not prose.
- Point at documents and examples. Do not copy them.
