# Agent review with a fresh context

A new session, without the history of whoever wrote the change.

- Axis 1, standards: the `AGENTS.md` rules, complexity limits, robustness, security, code smells.
- Axis 2, spec: the change does what the spec and the acceptance tests ask, no more and no less.
- A hostile stance: evidence over narrative. Read the diff, never only the agent's summary.
- Output: a list of problems with the file, the severity, and the proof.
