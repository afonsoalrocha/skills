# Report for the system owner

In the language of the system, without code (unless they ask):

```text
Slice N: <name>
What it delivers: <one or two sentences>
Acceptance tests: <x of y passing>
Metrics before and after: <CRAP, duplication, mutants>
Risks: <money, data, migrations, security>
Can it be reversed? <yes, with a feature flag / no, because...>
Needs you: <a decision or an approval still open>
```
