# Overall plan of the whole

A short list of vertical slices, each one line: what it delivers and for whom. No technical detail.

- A vertical slice crosses every layer and delivers something that can be demonstrated (a tracer bullet, Pocock).
- The first slice is the skeleton that already goes to production.
- Mark a dependency between slices only when it is real.
- Revise the plan after each slice is delivered. What was learned changes the next ones.
- Never detail a slice beyond the next one. The detail goes stale when the current slice is implemented.
